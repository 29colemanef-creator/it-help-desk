# School IT Help Desk

A help desk project for a high school, intended to give teachers a consistent way to report IT problems and help the IT team track them through resolution.

> **Project status:** This repository currently contains the project README. The application code and setup instructions have not been added yet.

## Planned features

### For teachers

- Submit a support ticket with a title, description, school email, room or location, issue category, urgency, and optional asset tag.
- Choose from these categories: Computer, Projector, Network, Software, or Other.
- Receive a submission confirmation and view submitted tickets.

### For IT staff

- View and filter tickets by status, urgency, category, and location.
- Assign tickets to technicians, update their status, and add staff notes.
- Track status history.

### Ticket statuses

`New` → `Assigned` → `In Progress` → `Waiting` → `Resolved` → `Closed`

## Privacy and security

This project is intended to support school IT operations. Do not include passwords, student records, or other sensitive information in ticket details. Any prototype using browser storage is for demonstration only; it is not appropriate for real school use without suitable authentication, access controls, secure storage, and a review by the school’s IT/security team.
